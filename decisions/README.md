# Executive Decision Records (EDR)

Denne mappen inneholder alle strategiske og langsiktige beslutninger for Minihus.

## Formål

EDR dokumenterer:

- hvorfor en beslutning ble tatt
- hvilke alternativer som ble vurdert
- hvilke konsekvenser beslutningen har
- når beslutningen skal revurderes

## Standard

Filnavn:

EDR-0001.md
EDR-0002.md
EDR-0003.md

Nummereringen er sekvensiell og endres aldri.
