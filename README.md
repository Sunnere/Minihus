# Minihus

Minihus er Sunnerehelses virksomhet for utvikling, investering og drift av små boliger og unike overnattingskonsepter.

## Mission

Bygge lønnsomme, skalerbare og bærekraftige minihusprosjekter med dokumenterte beslutninger og høy kvalitet.

## Vision

Skape en internasjonal portefølje av attraktive minihusdestinasjoner bygget på data, standardisering og langsiktig verdiskaping.

## Repositories

Dette repositoryet inneholder:

- Markedsanalyser
- Forretningsmodeller
- Finansielle modeller
- Juridisk dokumentasjon
- Partnerstrategier
- Roadmaps
- Executive Assets

Atlas leverer beslutningsstøtte og analyse.

BonusUnivers fungerer som vekstmotor når synergier finnes.
