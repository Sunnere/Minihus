# Financial Blueprint

Denne mappen inneholder de økonomiske modellene for Minihus.

Prinsipper:

- Alle beregninger skal være sporbare.
- Alle antakelser dokumenteres.
- Scenarioanalyse skal alltid inkludere:
  - Conservative
  - Expected
  - Optimistic

Målet er å bygge en investeringsmodell som kan oppdateres når nye markedsdata kommer inn.
